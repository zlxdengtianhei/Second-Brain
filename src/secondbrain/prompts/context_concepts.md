## Task: list the concepts of a source, by chunk

A source is cut into `chunks`, and each chunk is turned into cards by itself. List the concepts, methods, results and terms the source explains, each once, with the ids of the chunks that explain it (not the ones that only mention it), in the order the source first explains them. Use short names as the source writes them; no judgement and no cards.

Answer `{"concepts": [{"name": "...", "chunks": ["c01", ...]}, ...]}`.
