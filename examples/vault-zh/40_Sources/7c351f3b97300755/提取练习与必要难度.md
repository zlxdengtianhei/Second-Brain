# 提取练习与必要难度

## 提取练习

尝试从记忆中回想信息，比再读一遍更能巩固这条记忆。回答问题、把记得的内容全部写下来、不看笔记讲解一个概念，都属于提取（retrieval）。这叫提取练习（retrieval practice），也叫测试效应（testing effect）。在一个典型的实验中，学生先读一篇短文，然后要么再读一遍，要么写下自己能回忆起的内容，整个过程没有反馈。一周后测试，回忆组记住的内容更多，尽管重读组当时自我感觉更有把握。

即使没有反馈，提取也有帮助；但有反馈时效果更好：一次尝试失败后，看到正确答案，学习者就能纠正错误。抽认卡（flashcard）之所以有效，是因为每张卡都是一次小小的提取尝试，紧接着就有反馈。

## 流畅错觉

重读会让一篇文字显得眼熟。这种熟悉感很容易被误当成已经掌握：学习者认得出这些内容，却无法在没有任何提示的情况下自己说出来。这就是流畅错觉（illusion of fluency）。一个简单的检验办法是合上书，试着讲解这个概念，或者回答一个与它有关的问题。回想不起来的，就还没有学会。

## 交错练习

练习几类题目时，把它们混在一起做（A B C A C B），而不是做完一类再做下一类（A A A B B B C C C），之后的成绩会更好，在不提示题型的测试中尤其如此。交错练习（interleaving）迫使学习者为每道题选出正确的方法，而这正是考试要求的能力。分块练习（blocked practice）做起来更顺手，练习期间的得分也更高，所以学习者往往更喜欢它。

## 必要难度

间隔、提取和交错有一个共同的规律：它们让练习感觉更难、更慢，也让练习期间的表现变差，却能提高长期保持效果，以及向新问题的迁移（transfer）。心理学家罗伯特·比约克（Robert Bjork）把这类条件称为必要难度（desirable difficulties）。只有学习者付出努力后仍能成功，这种难度才算“必要难度”；任务太难，只会导致失败，学不到东西。

在练习期间测量，较容易的方法看起来更好。隔一段时间再测量，较难的方法胜出。凭当下的感觉来评判一种学习方法，会选错。
