## Essence
Mixing several kinds of problems (A B C A C B) instead of doing them in blocks (A A A B B B C C C) improves later performance, especially when the problem type is not announced.

## Propositions
- P1. Interleaving mixes problem types, for example A B C A C B.
- P2. Blocked practice does all problems of one kind before the next, for example A A A B B B C C C.
- P3. Interleaving improves later performance, especially on tests where the problem type is not announced.
- P4. Interleaving forces the learner to choose the right method for each problem, which is the skill an exam requires.
- P5. Blocked practice feels smoother and gives better scores during practice, which is why learners tend to prefer it.

## Intuition and contrasts
- Intuition: In blocked practice the type of problem tells you the method; in interleaved practice you must work out the method yourself, as in an exam.
- Contrast: Interleaving is not the same as spacing: interleaving mixes problem types in one session, while spacing separates repeated study over time.
