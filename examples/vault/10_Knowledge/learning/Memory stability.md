## Essence
The stability of a memory is the time it takes for the probability of recalling it to drop to a set level, such as 90 percent.

## Propositions
- P1. One memory can be described by a single number, its stability.
- P2. Stability is the time it takes for the probability of recall to drop to a set level, for example 90 percent.
- P3. A memory with low stability fades within days.
- P4. A memory with high stability lasts for months.
