## Essence
Spacing does not help much if each session is passive rereading; the benefit is largest when each session asks the learner to recall the material.

## Propositions
- P1. Spacing does not help much if each session is passive rereading.
- P2. The benefit is largest when each spaced session asks the learner to recall the material, not only to look at it again.

## Intuition and contrasts
- Contrast: Spreading out rereading sessions is not the same as spaced retrieval practice; only the latter gives the full benefit.
