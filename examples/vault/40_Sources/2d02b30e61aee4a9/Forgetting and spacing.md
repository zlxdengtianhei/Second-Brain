# Forgetting and spacing

Notes for the Thursday study group. Bring questions for next week.

## The forgetting curve

In the 1880s Hermann Ebbinghaus learned lists of nonsense syllables and measured how much he could still recall after different delays. Memory loss was fastest right after learning and slowed down over time: much of what was lost went in the first day, and what survived a week tended to survive much longer. This shape is called the forgetting curve. The exact rate depends on the material, on how meaningful it is and on how well it was learned in the first place; meaningful material is forgotten more slowly than nonsense syllables.

A useful way to describe one memory is a single number, its stability: the time it takes for the probability of recalling the memory to drop to a set level, for example 90 percent. A memory with low stability fades within days. A memory with high stability lasts for months.

## The spacing effect

Studying the same material in several sessions spread over time leads to better long-term retention than studying it for the same total time in one session. This is the spacing effect, one of the most often replicated findings in memory research. Cramming the night before a test can give a good score the next morning, but much of that knowledge is gone a few weeks later. Spaced study wins on any test given after a delay; massed study can win only on a test given right away.

One explanation: a review that comes after some forgetting has started forces a more effortful retrieval, and a successful effortful retrieval increases stability more than an easy one.

## Expanding intervals

If each successful review makes a memory more stable, the next review can wait longer. Spaced repetition systems use this. After each successful review the interval to the next review grows, for example 1 day, 3 days, 8 days, 3 weeks. A failed review shortens the interval again. Schedulers such as the SM-2 algorithm and FSRS estimate, for each card, when the probability of recall will fall to a target level (often 90 percent) and schedule the review for about that moment. Reviewing much earlier spends time on something that is still well known; reviewing much later means relearning it.

## Limits

Spacing does not help much if each session is passive rereading. The benefit is largest when each spaced session asks the learner to recall the material, not only to look at it again.
